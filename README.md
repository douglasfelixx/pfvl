# Portal PFVL

Portal PFVL com interface React/Vite, API Express, PostgreSQL no Neon, autenticação Clerk e arquivos de mídia no Cloudflare R2.

## Atualizar o repositório GitHub

Extraia o conteúdo deste ZIP sobre a cópia local do repositório, confira as alterações e faça o commit normalmente. O pacote não inclui credenciais, dependências instaladas ou arquivos locais.

## Publicar na Vercel

Importe o repositório com a raiz como diretório do projeto. A configuração de build e os caminhos da API estão em `vercel.json`. Configure as variáveis de ambiente da Vercel conforme `.env.example` e `DEPLOYMENT.md`; não envie valores secretos ao GitHub.
